# Практическая работа №1.2 — Связи таблиц в Sequelize

## Цель работы

Закрепить навыки определения ассоциаций между моделями Sequelize, создания связанных записей, использования специальных методов экземпляров и получения связанных данных с помощью опции `include`.

## Предметная область

Проект моделирует авторов и их книги.

Используется связь **«один ко многим» (1:N)**: один автор может иметь несколько книг, а каждая книга принадлежит одному автору.

## Описание моделей

### Author — автор

| Поле | Тип данных | Описание |
|---|---|---|
| `name` | STRING | Имя автора |
| `country` | STRING | Страна автора |

### Book — книга

| Поле | Тип данных | Описание |
|---|---|---|
| `title` | STRING | Название книги |
| `year` | INTEGER | Год издания |
| `genre` | STRING | Жанр книги |
| `authorId` | INTEGER | Внешний ключ автора |

Все основные поля моделей обязательны для заполнения. Поле `authorId` используется для связи книги с автором.

## Реализация ассоциаций

Для определения связи используются два метода Sequelize:

- `Author.hasMany(Book)` — один автор может иметь несколько книг.
- `Book.belongsTo(Author)` — каждая книга принадлежит одному автору.

В ассоциациях явно указан внешний ключ `authorId`. Для связи автора с книгами используется псевдоним `books`, который применяется при выполнении запроса с `include`.

## Реализованные функции

1. Подключение к базе данных SQLite с помощью Sequelize.
2. Проверка подключения методом `authenticate()`.
3. Создание таблиц с помощью `sequelize.sync({ force: true })`.
4. Создание автора Льва Толстого.
5. Добавление книг «Война и мир» и «Анна Каренина».
6. Создание связанных записей с помощью метода `createBook()`.
7. Подсчёт количества книг автора с помощью `countBooks()`.
8. Получение авторов вместе с их книгами через `include`.
9. Вывод результатов в консоль.
10. Закрытие соединения с помощью `sequelize.close()`.
